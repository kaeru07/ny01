## 記事本文

2026年8月17日の調査では、単にコードを生成するAIよりも、必要な機能を発見し、外部サービスへ接続し、実行結果を人が検証できる基盤へ競争の軸が移っていることが鮮明になった。GitHub Agent Finderは、増え続けるMCPサーバーやスキルを常時コンテキストへ詰め込まず、タスクに応じて探索する仕組みを提供する。これはトークン消費と設定作業を抑えたい個人開発者にも直接的な価値がある。

技術面で最も重要な変化は、7月28日版MCP仕様のステートレス化である。従来の長時間セッションへの依存を減らし、一般的なHTTPロードバランサーやキャッシュを利用しやすくした。長時間処理用のTasks拡張、承認を扱う複数往復リクエスト、認可強化も加わり、MCPはローカル実験用の接続規約から運用基盤へ近づいた。一方、既存サーバーには移行作業が発生するため、仕様対応だけを理由に即時更新するのではなく、SDKと接続先クライアントの互換性を先に試すべきである。

収益化の観点では、Codex SitesやRayfinのような「生成して共有・運用まで進める」製品が注目に値する。個人開発者は汎用チャットを再販するより、特定業種の入力、判断、成果物を一続きにした小型サービスを短期間で販売しやすくなる。ただし、企業向けプレビューや基盤利用料へ依存する製品は原価と移植性が読みにくい。最初から全面採用せず、課金導線と固有データだけを自前に残す設計が安全である。

SnapCodeやAgentforce Mobile SDKは外部システム連携を短縮するが、現時点では個人向け料金の確認が足りず、最初のMVPには重い可能性がある。反対に、GitHub Agent Finderと公式MCP SDKは小さく試せる。まず一つの収益候補、例えば学習記録や将棋・麻雀の対局振り返りを選び、調査、コンテンツ生成、公開前承認だけをMCPツール化するのがよい。処理時間、推論費、手動修正時間、課金転換率を一週間記録すれば、エージェント化が利益を増やしたかを判断できる。

次の一歩は、既存のMCP実装を2026-07-28仕様へ直ちに全面移行することではなく、認証情報を使わない検証サーバーで互換性テストを作ることである。その上でGitHub Agent Finderによる発見性と、Claude CodeまたはCodexからの呼び出しを確認する。短期リリースを優先し、企業向け製品は価格と利用規約が確認できるまで比較対象に留める。

## 個人開発で活用できそうなもの

- GitHub Agent Finder: 学習アプリやコンテンツ生成サービスの開発時に、必要なMCP・スキルだけを探索して導入候補を絞る。無料プランから検証できる。

- GitHub Copilot cloud agent: issueから修正、テスト、PR作成まで委任する。課金: Proは10米ドル/月、Pro+は39米ドル/月、Maxは100米ドル/月。無料枠あり。ただし第三者エージェントの対象プランには公式ページ内で記述差があり、契約前確認が必要。[料金](https://github.com/features/copilot/plans)
