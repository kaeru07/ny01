## 記事本文

今日の調査で強く見えたのは、新しい生成モデルそのものより、エージェントを安全に接続し、複数環境で再利用するための基盤整備である。GitHubではAgent Plugins 1.0が公開され、スキルとMCPサーバーを一つの配布単位にまとめられるようになった。従来はClaude Code、Codex、Copilotなど利用先ごとに設定やパッケージを作り直しがちだったが、今後は共通部分を保ったままクライアント固有機能を追加する設計へ移りやすい。[GitHub公式発表](https://github.blog/changelog/2026-08-12-agent-plugins-1-0-in-vs-code-copilot-cli-and-the-copilot-app/)

同時に、モデル選択の競争も続いている。GitHub CopilotにはGemini 3.7 FlashとGrok 4.6が追加され、Web・アプリ開発、コードベース調査、長時間のツール利用を伴う作業が主な用途として示された。Cursorもクラウドエージェントの起動高速化や実行基盤の改善を進めている。これは「最高性能のモデルを一つ選ぶ」段階から、速度、費用、長期推論の必要性に応じてモデルとエージェントを使い分ける段階へ移ったことを意味する。[Gemini 3.7 Flash発表](https://github.blog/changelog/2026-08-13-gemini-3-7-flash-is-now-available-in-github-copilot/) [Grok 4.6発表](https://github.blog/changelog/2026-08-14-grok-4-6-is-now-available-in-github-copilot/)

個人開発の収益化では、汎用チャットをもう一つ作るより、特定業務の手順、データ取得、成果物生成をまとめた小型プラグインの方が短期リリースに向く。たとえばApp Storeレビューの分類、学習問題の生成と検査、麻雀牌譜の解説、短尺動画用の台本作成などを、スキルとMCPツールの組として提供できる。月額課金だけでなく、セットアップ代行、テンプレート販売、業種別プラグインの買い切り販売も検討できる。ただし、外部サービスへ書き込むMCPでは権限分離と操作確認が商品価値の前提になる。

次に取るべき一歩は、一週間で検証できる小さなプラグインを一つ作ることである。入力を公開情報に限定し、CodexまたはClaude Codeから呼び出せる読み取り専用MCPと、結果をMarkdownへ整形するスキルを組み合わせる。まず無料枠内で処理時間、誤り率、利用一回当たりの推定原価を計測し、手作業より十分速いと確認できた段階で月額500〜1,500円程度の小規模サービスへ展開するのが現実的である。

## 個人開発で活用できそうなもの

- Agent Plugins 1.0: 調査手順とMCP接続を一つにまとめ、複数の対応エージェントへ配布する。業種別テンプレート販売と相性がよい。
- GitHub Copilot Free／Pro: Issueから実装・レビューまでを一つのリポジトリ上で回す。無料枠あり、Proは課金: 10ドル/月。
- Cursor Cloud Agents: 独立した小機能やテスト修正を並列委任し、少人数でもリリース頻度を上げる。無料枠あり、Proは課金: 20ドル/月。
- Gemini 3.7 Flash: 大量の画面案、説明文、テストケース生成など、速度と反復回数を重視する作業候補。実際の利用単価は選択サービスごとに要確認。
- Grok 4.6: 長い実装や複数ツールを使う調査・修正へ割り当てる候補。従量課金のため、上限予算を設定して検証する。
