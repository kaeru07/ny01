- AI SDK 7 / Vercel / AIエージェント開発SDK / Codex・Claude Codeなどを共通インターフェースで実行し、永続ワークフロー、承認、MCP Apps、監視を組み込める / 価格帯: 無料（Apache-2.0、セルフホスト可。モデル利用料・実行基盤は別途）

## 記事本文

2026年8月14日の調査では、当日公開の大型AIツールより、6月から7月に登場したエージェント実装基盤を個人開発の収益化工程へどう取り込むかが主要テーマになった。特にVercel AI SDK 7は、モデルを呼ぶための薄いライブラリから、承認、永続実行、監視、MCP Apps、外部コーディングエージェントまで扱う基盤へ拡張されている。8月14日当日の新規公式発表は確認できていないため、ここでの「新規」は昨日の調査に未掲載だった直近機能を指す。

観測した変化は、CodexやClaude Codeを開発者が直接操作するだけでなく、SaaSの内部機能として呼び出せるようになったことである。HarnessAgentを使えば、同じ画面と業務フローを維持したままエージェント実装を交換できる。WorkflowAgentは再起動や承認待ちをまたぐ処理を保存できるため、調査、生成、検査、公開候補作成という数十分以上の工程にも適する。一方、Node.js 22とESMが必須であり、既存サービスへの移行では互換性確認が必要になる。

収益化への意味は、汎用チャットをもう一つ作ることではなく、結果が明確な縦特化ワークフローを有料化しやすくなる点にある。例えば、学習問題の生成と誤答分析、麻雀牌譜からの復習問題作成、アプリストア説明文の多言語化と品質検査を、一回課金または月間件数制で提供できる。AI SDK自体は無料かつセルフホスト可能だが、モデル、サンドボックス、保存領域には従量原価が発生する。Vercel Agentは基盤処理が100万トークン当たり0.25ドルに変更され、別途モデル推論費用も必要なため、定額使い放題より利用上限付きプランが安全である。

また、Agent Finderの登場は、MCPやスキルをすべて常時読み込む設計から、必要な資源を実行時に発見する設計への移行を示している。個人開発ではコンテキスト消費を抑えられる一方、未知のツールを自動接続すると権限事故につながる。Agent Finderは自動インストールを行わないため、候補発見と人間による承認を分離できる点が実用的である。GitHub MCP Serverもローカル実行、読み取り専用、Lockdown Modeを選べるため、小規模運営でも最小権限を作りやすい。

次に取るべき一歩は、AI SDK 7とHarnessAgentを使い、入力一件から検査済み成果物を一件返す小さな有料候補を作ることである。最初は一問一答教材生成など出力品質を採点しやすい用途に限定し、実行時間、総トークン費、成功率、人手修正時間を記録する。その数値から一件当たり原価の三倍以上を販売価格に設定できるか確認し、成立した場合だけ永続実行やMCP連携を追加するのが妥当である。

## 個人開発で活用できそうなもの

- AI SDK 7：複数モデル対応の学習アプリや診断サービスを一つのTypeScript基盤で実装する。SDKは無料・セルフホスト可で、推論費用のみ利用量に応じて管理できる。
- HarnessAgent：CodexとClaude Codeの実行結果、原価、成功率を同じテストセットで比較する。特定エージェントへの依存を抑えた受託自動化にも使える。
- WorkflowAgent：長時間の商品調査、教材生成、記事検査を中断可能なジョブとして提供する。月額制より「月20件まで」のような件数制と相性がよい。
- eve Agent Observability：失敗した生成処理とトークン浪費を特定し、ユーザー単位の粗利を改善する。Hobbyは12時間保持の無料枠あり。
- GitHub Agent Finder：新しいMCPやスキルを必要時だけ探し、コンテキスト量と設定作業を削減する。接続前の権限審査は人間が行う。

## Claude Code/Codex連携可能性

- AI SDK 7 HarnessAgent：公式アダプターを通じてClaude CodeまたはCodexを同じAgent APIから実行し、UIや永続処理へ組み込む。
- AI SDK Skill：`SKILL.md`と関連ファイルをコーディングエージェントへ追加し、Claude CodeやCodexによるAI SDK実装・移行を支援する。
- GitHub MCP Server：Claude CodeなどのMCPホストからIssue、PR、コード検索を操作する。MITライセンスでローカル実行・セルフホスト可。
- Agent Finder：タスク記述から必要なMCP、スキル、ツールを検索し、許可したものだけをエージェントへ追加する。
- MCP Apps：AI SDK 7のサンドボックス化iframeへツール固有UIを表示し、CodexやClaude Codeが生成した処理結果を操作可能な画面として提供する。

## MCP/Agent系情報

- AI SDK 7はMCP Apps、構造化出力、リソースリンク、OAuth、SSEを扱うMCPクライアント機能を追加した。公式情報: [Vercel AI SDK 7](https://vercel.com/changelog/ai-sdk-7)、リポジトリ: [vercel/ai](https://github.com/vercel/ai)
- HarnessAgentはCodex、Claude Code、Piなどを共通のAgent APIへ統合する。公式情報: [Program agent harnesses with AI SDK](https://vercel.com/changelog/program-agent-harnesses-with-ai-sdk)
- GitHub Agent FinderはオープンなARD仕様を利用し、登録済みのMCPサーバー、スキル、エージェントを検索する。自動インストールは行わない。公式情報: [GitHub Agent Finder](https://github.blog/changelog/2026-06-17-agent-finder-for-github-copilot-now-available/)
- GitHub MCP Serverは次期MCP仕様のステートレスコアへ対応し、セッション依存を削減した。公式情報: [GitHub Changelog](https://github.blog/changelog/2026-07-23-github-mcp-server-supports-the-next-mcp-specification/)、リポジトリ: [github/github-mcp-server](https://github.com/github/github-mcp-server)
