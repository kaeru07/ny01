## 前提

- 最終技術スタック: Expo (React Native) / Codemagic

- Bundle ID 候補: `com.kaeru07.mahjonganalyzer`

## 現在地

Web 基準実装では、13枚の有効牌表示、14枚の打牌候補表示、入力エラー、
下書きの復元・自動再解析までブラウザ実操作で確認済み。解析ロジックと
下書き検証には回帰テストがある。

Expo 版も構築済みで、解析、端末内下書き保存・復元、オフライン案内、
Safe Area、キーボード回避、ロード・空・エラー状態を実装済み。Linux 環境で
Expo Web 出力までは検証済みだが、iOS シミュレーター／実機での受入確認と
Codemagic 検証ビルドは未実施。このため、現時点では App Store 提出準備完了ではない。

## ストア文言案

- アプリ名: 麻雀手牌解析
- サブタイトル: 有効牌と受け入れ枚数をすぐ確認
- カテゴリ候補: ゲーム / ユーティリティ
- プロモーションテキスト案: 手牌を入力するだけで、シャンテン数・有効牌・打牌候補を端末内で解析します。
- キーワード案: 麻雀,手牌,シャンテン,有効牌,受け入れ,牌効率,打牌
- 説明文案:

  麻雀手牌解析は、13枚または14枚の手牌を入力して牌効率を確認できる無料ツールです。
  13枚ではシャンテン数、有効牌と受け入れ枚数を、14枚では打牌候補ごとの有効牌と
  受け入れ枚数を表示します。入力内容は端末内だけに保存され、外部へ送信されません。

- 審査メモ案:

  アカウント登録と課金はありません。起動後、入力欄下のサンプルを選ぶとすぐに解析を
  確認できます。解析は端末内で完結し、ネットワーク接続を必要としません。

## iOS 受入確認手順

次の順に1周し、クラッシュ、白画面、見切れ、操作不能がないことを確認する。

1. 初回起動時に空状態が表示され、無効な枚数では解析ボタンが無効である。
2. `123m456p789s11z12m` を入力し、13枚の有効牌・受け入れ枚数が表示される。
3. `123m456p789s11z12m5p` を入力し、14枚の打牌候補を展開・折りたたみできる。
4. アプリを完全終了して再起動し、最後の入力と解析結果が復元される。
5. 機内モードで再起動し、オフライン案内が表示されたまま解析できる。
6. 縦向き・横向きの両方で、ノッチ、Home Indicator、キーボードに主要操作が隠れない。
7. iOS の「さらに大きな文字」の最大サイズで、テキストが重ならず、縦スクロールで全操作に到達できる。
8. VoiceOver で入力欄、解析、クリア、サンプル、候補展開の用途と状態が読み上げられる。
